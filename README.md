# String Length Using Return Value in C

This program uses a user-defined function to find and return the length
of a string.

## File

string_length.c

## Concepts Used

- Function return value
- Function parameter
- Function call
- Character array
- while loop

## How to Run

gcc string_length.c -o string_length
./string_length

## Sample Output

Enter a string: Hello
String Length = 6
